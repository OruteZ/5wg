# Progression

성장 축의 기획 — 경험치, 레벨업, 카드 선택. 무기 자체는 `weapons.md`에 있다.

이 문서는 문답으로 확정한 내용만 담는다. **"미정"으로 적힌 것은 아직 결정되지 않은 것이지
생략된 것이 아니다** — 채우지 말고 물어야 한다.

## 한 줄 요약

**레벨업의 쾌감과 음악의 쾌감이 같은 순간에 와야 한다.** 그래서 경험치도 레벨업도 박에 맞고,
카드가 떠도 음악은 끊기지 않는다.

## 레벨업 페이스

| 항목 | 값 |
| --- | --- |
| 한 스테이지 | 15~20분 |
| 목표 레벨업 횟수 | **40회 내외** |
| 요구 경험치 | `5 + 3 × (레벨 - 1)` (선형 증가) |
| 40회까지 누적 | 2,540 |
| 적 1마리 | 경험치 1 |
| 필요 처치 수 | 18분 기준 **분당 약 140마리** |

### 곡선이 만드는 리듬

| 카드 회차 | 누적 경험치 | 도달 시점(분당 140 기준) |
| --- | --- | --- |
| 10회 | 185 | 약 1.3분 |
| 20회 | 670 | 약 4.8분 |
| 30회 | 1,455 | 약 10.3분 |
| 40회 | 2,540 | 약 18분 |

초반엔 빠르게 터지고 후반으로 갈수록 느려진다. 지수 곡선(VS식)을 쓰지 않은 이유는
**선택이 실시간이기 때문**이다 — 초반 1~2분에 카드가 10번 넘게 뜨면 시야를 계속 가린다.

### 강화 칸이 모자란 것은 의도다

한 판의 강화 칸은 6슬롯 × 5레벨 = **30개**인데 카드는 **40회** 뜬다.
30칸이 다 차면 남은 약 10회는 고를 무기 강화가 없다. 그 회차는 소모성 보상 구간이다.

## 카드 선택

### 형태

- 레벨업 **1회 = 카드 3장 중 택1**.
- 후보 풀은 **신규 무기 획득 + 기존 무기 강화 혼합**.
- 빈 슬롯 1개당 신규 무기 가중치 +1. 초반엔 신규가 잘 뜨고 슬롯이 찰수록 강화로 기운다.
- 슬롯이 꽉 차면 **강화만** 나온다.
- 같은 라운드에 같은 항목이 중복으로 뜨지 않는다.
- **희귀도 없음, 후보 간 균등.** 10종뿐이라 희귀도를 넣으면 원하는 무기를 못 만나는 판이 생긴다.

### 3장을 못 채울 때

남은 후보 수만큼만 띄운다(2장 또는 1장). 후보가 하나도 없으면 카드를 띄우지 않고
**힐 또는 상점 화폐를 자동 적용**한다. 후반 소모성 보상 구간에서는 힐과 화폐가 나오며,
화폐량은 스테이지 후반일수록 커진다.

### 조작 — 아무것도 멈추지 않는다

**카드가 떠 있어도 게임은 계속 돈다.** 음악도, 적도, 발사도.

| 항목 | 규칙 |
| --- | --- |
| 입력 | 마우스 클릭 + 숫자키 1·2·3 |
| 위치 | 화면 중앙 하단 |
| 고르지 않으면 | 무한 대기. 그동안 경험치는 계속 쌓인다 |
| 대기 중 또 레벨업하면 | 큐로 쌓아 순서대로 소진 |

시간을 멈추지 않는 이유는 **음악을 끊지 않기 위해서**다. `Time.timeScale`은 애초에 쓸 수 없다 —
`BpmClock`이 `AudioSettings.dspTime` 기준이라 timeScale로는 박이 멈추지 않고 화면과 어긋나기만 한다.

## 박자 동기화

경험치 흐름 전체가 박에 맞는다. 이게 레벨업을 음악적 사건으로 만든다.

- **오브 흡수** — 오브가 수집 범위에 들어온 순간 곧바로 빨려오지 않는다.
  **가장 가까운 다음 정박에 플레이어에게 도착하도록** 이동 속도를 맞춘다.
  여러 오브가 한 박에 함께 도착하면 소리도 한 번에 나서 그 자체로 리듬이 된다.
- **너무 촉박하면 한 박 미룬다** — 다음 박까지 남은 시간이 한 박의 30% 미만이면
  그다음 박을 목표로 잡는다. 순간이동처럼 보이는 것을 막는다.
- **정박 기준.** 서브박(8분·16분)까지 허용하면 사실상 아무 때나 들어와
  "박에 맞춰 들어온다"는 감각이 사라진다.
- **레벨업 시점** — 경험치가 들어오는 순간이 이미 박이므로 레벨업도 자연히 박에 맞는다.
  별도 지연을 두지 않는다.

120BPM 기준 최대 지연은 0.5초이고, 오브가 날아오는 시간이 그 지연을 시각적으로 채운다.

## 영구 강화와의 접점

런 사이 메타 상점(영구 강화 구매)이 있다. **상점 설계는 별도 문서**로 분리하며
이 문서에는 무기 스탯과의 합산 계약만 남긴다.

적용 순서는 이렇게 고정한다.

```
무기 레벨 표(절대값) → 그 판의 카드 강화 → 영구 강화
```

영구 강화는 **합연산**이다. 레벨 표 값에 그대로 더한다.

> 참고: 레벨 표가 절대값이라 합연산을 섞으면 표만 보고 최종 수치를 알 수 없다.
> 곱연산이면 표가 항상 기준값으로 남는다는 이점이 있었으나, 합연산으로 결정됐다.
> 수치 튜닝 시 표와 실제 값이 벌어지는 것을 감안해야 한다.

## 미정

- **상점 설계 전반** — 무엇을 파는가, 화폐 획득량, 해금 구조, 세이브. 별도 문서.
- **소모성 보상의 수치** — 힐량, 화폐량, 후반 증가 곡선.
- **카드 UI 연출** — 등장 방식, 곡의 마디와 맞출지 여부.
- **패시브 아이템** — VS의 패시브 슬롯에 해당하는 축. 이번 범위 밖으로 뒀다.
  무기 축이 굳은 뒤에 슬롯·카드 풀·스탯 합산을 함께 설계한다.
