# Enemies

적, 스폰 디렉터, 엘리트, 보스 기획. 노션 `[10-12]`의 확정분을 옮긴 것이다.

**"미정"으로 적힌 것은 아직 결정되지 않은 것이지 생략된 것이 아니다** — 채우지 말고 물어야 한다.

## 구성

스테이지당 일반 적 7종 + 엘리트 + 보스. 회차마다 신규 적이 추가된다.

| 회차 | 시간 | 신규 등장 | 누적 |
| --- | --- | --- | --- |
| 1회차 | 0-4분 | 3종 | 3 |
| 2회차 | 4-8분 | 2종 | 5 |
| 3회차 | 8-12분 | 2종 | 7 |
| 4회차 | 12-15분 | 보스 | 7 + 보스 |

## 이동

- **연속 이동 + 박 펄스.** 적은 부드럽게 계속 이동하고, 박마다 몸체를 살짝 확대했다 줄이거나
  색을 튀긴다. 박 단위 스냅 이동을 쓰지 않는다.
- **적 속도는 BPM에 연동되지 않는다.** 초당 고정이다.
- 이동 방향은 플레이어를 향한 직선이다.

박 펄스는 구현돼 있다. 크기로만 표현하고 색은 쓰지 않는다 — 피격 색과 겹치면 맞은 것이 안 보인다.

## HP 곡선

시간에 따라 오르는 곡선은 **하나만** 둔다. 적 종류별 차이는 이 값에 곱하는 배수로 표현한다.

| 시점 | 0분 | 2분 | 4분 | 6분 | 8분 | 10분 | 12분 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 기본 HP (배수 1.0) | 10 | 14 | 20 | 42 | 110 | 127 | 188 |

중간 시점은 선형 보간한다. 12분 이후는 188로 유지한다.

이 곡선은 목표 TTK에서 역산한 값이다. 플레이어 DPS 곡선(0분 10 → 13.5분 500)이 바뀌면
이 표도 같은 비율로 다시 계산해야 한다.

## 스폰 디렉터

스폰 방식은 **혼합**이다. 평상시는 가중치 추첨으로 돌아가고, 정해진 시점에 지정 웨이브를 얹는다.

### 시점의 단위 — 사건은 마디, 곡선은 초

아래 표들의 분·초 표기는 **120BPM 4/4 기준 환산값**이다. 실제로 에셋에 적는 값은 마디다.

| | 단위 | 이유 |
| --- | --- | --- |
| 회차 시작, 지정 웨이브, 엘리트, 보스 | **마디** | 곡 구조상의 위치다. 곡 길이를 몇 마디로 정하느냐가 회차 길이를 정한다 |
| 기본 HP, 스폰율, 목표 적 수 | **초** | 초당 밸런스다. DPS·TTK가 BPM 비연동이라 마디로 옮기면 BPM만 올려도 난이도가 빨라진다 |

120BPM 4/4에서 1마디는 2초다. 회차 시작은 0 / 120 / 240 / 360마디, 웨이브는
60 / 105 / 180 / 225 / 300 / 345마디, 엘리트는 180마디부터 45마디 간격이다.

**BPM을 크게 바꾸면 둘이 벌어진다.** 60BPM에서 같은 마디 수는 초로 두 배가 되므로,
곡의 마디 수는 회차가 4분 내외가 되도록 BPM과 같이 정한다.

목표 적 수를 정하고 스폰율을 역산한다. 스폰율을 직접 정하지 않는다.

```
스폰율 = 처치율 + (목표 적 수의 변화율)
```

| 시점 | 목표 화면 내 적 수 | 필요 스폰율 (마리/초) |
| --- | --- | --- |
| 0분 | 15 | 1.2 |
| 2분 | 40 | 2.1 |
| 4분 | 70 | 3.6 |
| 6분 | 120 | 4.6 |
| 8분 | 180 | 4.1 |
| 10분 | 250 | 9.9 |
| 12분 | 250 | 22.3 |
| 13.5분 | 100 | 5.0 |

10분 이후에는 적 수가 상한에 붙는다. 스폰율은 처치율과 같아진다.

### 평상시 구성 — 회차별 가중치

등장 시점이 지난 적 중에서 가중치에 비례해 뽑는다. 회차가 바뀌면 표가 바뀐다.

| 회차 | 악보 0.6 | \[0.8\] | 메트로놈 1.0 | \[1.9\] | 앰프 3.4 | \[2.0\] | \[2.9\] |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1곡 (0-4분) | 45 | 30 | 25 | - | - | - | - |
| 2곡 (4-8분) | 25 | 22 | 22 | 28 | 3 | - | - |
| 3곡 (8-12분) | 15 | 15 | 15 | 22 | 3 | 30 | - |
| 4곡 (12-15분) | 10 | 10 | 10 | 15 | 5 | 22 | 28 |

앰프는 평상시 가중치를 낮게 둔다. 떼로 나오는 것은 지정 웨이브에서만이다.

### 지정 웨이브

평상시 스폰 위에 얹는다. 시점은 판 시작 후 절대 시간이다.

| 시점 | 구성 | 배치 | 성격 |
| --- | --- | --- | --- |
| 2분 | 악보 40 | 한방향 | 물량 |
| 3분 30초 | 메트로놈 30 | 원형 | 가둠 |
| 6분 | 앰프 35 | 한방향 | 체급 벽 |
| 7분 30초 | 앰프 25 + \[1.9\] 40 | 랜덤 | **압박 정점** |
| 10분 | \[2.0\] 60 | 원형 | 물량 |
| 11분 30초 | 앰프 40 + \[2.9\] 40 | 랜덤 | 마지막 벽 |

곡 중반과 곡 끝 직전에 하나씩 둔다. 곡 끝 웨이브를 뚫으면 회차가 전환되고 상점이 열린다.
4곡에는 지정 웨이브를 두지 않는다. 보스가 그 자리를 대신한다.

웨이브가 진행되는 동안에도 평상시 스폰은 계속한다.

### 배치 형태 3종

| 형태 | 내용 |
| --- | --- |
| 랜덤 | 플레이어 주변 원주에 무작위 배치 |
| 한방향 | 한 방향에 모아서 배치. 반대편으로 도망칠 수 있다 |
| 원형 | 플레이어를 둘러싸도록 배치. 어느 쪽으로 가도 뚫어야 한다 |

### 스폰 위치

- 플레이어 기준 **반경 14**의 원주. 방향은 배치 형태가 정한다.
- 카메라 직교 크기 6 기준 중심-모서리 거리가 12.3이다. 반경 14는 어느 방향이든 화면 밖이다.

### 밀도

| 항목 | 값 |
| --- | --- |
| 평상시 목표 상한 | **250** |
| 하드 상한 | **300** |
| 웨이브 | 평상시 상한을 넘겨도 된다. 하드 상한만 지킨다 |
| 하드 상한 도달 시 | 스폰 중단 |
| 디스폰 조건 | 플레이어에게서 **스폰 반경의 2배(28)**를 넘어가면 회수하고 반대편에 다시 스폰한다 |
| 디스폰된 적의 보상 | **없다.** 보상 이벤트를 발행하지 않는다 |

느린 적(앰프 0.5배)은 플레이어를 따라잡지 못하고 뒤에 처진다. 디스폰이 없으면 이런 적들이
상한 슬롯을 영구히 점유해 화면 주변 밀도가 무너진다.

한 판 총 처치 수는 약 6,200마리, 12분까지는 약 4,100마리다.
경험치 곡선과 티켓 획득량이 이 값을 전제로 계산돼 있다.

## 엘리트

| 항목 | 값 |
| --- | --- |
| 등장 시점 | 6분부터 |
| 등장 주기 | **90초 간격** |
| 한 판 등장 수 | 5마리 (6:00 / 7:30 / 9:00 / 10:30 / 12:00) |
| 처치 보상 | 상자 1개 |
| HP 배수 / 크기 / 속도 | 미정 |

- 일반 적의 강화판이다. 별도 스프라이트를 만들지 않는다.
- 상자는 보유 무기·패시브 중 1-5개를 무작위 강화한다. 개수별 확률은
  10% / 25% / 30% / 25% / 10%로 평균 3개다.
- 한 판 상자 강화 15회는 성장 곡선 총 67회에 이미 포함돼 있다.
  주기나 개수를 바꾸면 성장률 `r = 1.0601`을 다시 계산해야 한다.

## 보스

4회차 전용이다.

**패턴을 두지 않는다.** 플레이어를 향해 직선으로 오는 일반 적과 같은 동작이고, 체급만 크게
다르다. 페이즈도 없다.

| 항목 | 값 |
| --- | --- |
| 이름 | 미정 |
| 등장 시점 | 12분 (3회차 → 4회차 전환) |
| HP | **25,000** |
| 목표 처치 시간 | 60-90초 |
| 이동 속도 | **0.4배** |
| 접촉 데미지 | 35 |
| 크기 | 일반 적의 3배 |
| 스프라이트 | **전용으로 만든다.** 생김새는 미정 |
| 넉백 | 받지 않는다 |
| 디스폰 | 되지 않는다. 반경 28을 넘어도 유지한다 |
| 페이즈 | 없다 |
| 패턴 | 없다. 플레이어를 향한 직선 이동만 |
| 일반 적 스폰 | 보스전 중에도 그대로 계속한다 |
| 제한 시간 | 2-3분 (4회차 길이). 넘기면 패배 |
| 처치 시 | **즉시 승리. 결과 화면으로 간다.** 남은 적을 정리하지 않는다 |
| 처치 보상 | 미정 |

HP 25,000은 13.5분 시점 DPS 500 기준 순수 딜 50초다.

속도 0.4배는 앰프(0.5배)보다 느리다. 도망치면서 딜을 넣는 구도가 성립하려면 플레이어보다
느려야 한다.

디스폰 예외가 필요하다. 일반 적은 반경 28을 넘으면 회수되는데 보스가 그러면 도망만 다니다
보스가 사라진다.

**넉백 면역과 디스폰 면역만 특수 처리하면 되고**, 나머지는 적 정의 값으로 표현한다.
보스 전용 클래스를 따로 만들 필요가 없다.

승리 판정과 결과 화면은 `StageDirector` 쪽 일이다. 적 작업 범위 밖이다.

## 스테이지 2 (재즈)

전체 미정. 적 7종, 엘리트, 보스 모두.

## 구현 메모

`Enemy`는 `IDamageable` `IPooledObject<Enemy>`를 구현하고 `TargetRegistry`에 등록·해제한다.
`OnDiedWithReward`로 사망 위치와 보상을 알리고, 스포너의 `HandleEnemyDied`가 그걸 받아
드랍을 처리한다. 이 구조는 유지한다.

디스폰 회수는 `OnDiedWithReward`를 발행하지 않는다. 보상 없이 풀로만 돌려보낸다.
도망만 다녀도 보상이 들어오면 성장 곡선이 무너진다.

구조와 결정 사항은 `architecture.md`의 "적과 스폰" 절에 있다. 여기는 기획 수치만 둔다.

### 아직 안 된 것

- **음표 종류별 분포.** 지금은 적의 음표 *개수*가 그대로 경험치 값이 된다.
- **상자.** 엘리트를 잡으면 `OnEliteDefeated`가 발행되지만 받는 쪽이 없다.
- **보스 승리 판정.** `OnBossDefeated`도 마찬가지다. 4회차 제한 시간도 없다.
- **회차 전환.** 디렉터는 회차를 가중치 표 고르기에만 쓴다. 상점·곡 전환과 연결돼 있지 않다.
- **적 종류별 스프라이트.** 7종 + 보스가 전부 같은 프리팹을 쓴다. 지금은 색으로만 구분한다.

### 임시 구분색

스프라이트가 나올 때까지 종류를 화면에서 가르는 유일한 단서다. 체급이 읽히도록
**약할수록 밝고 단단할수록 진하게** 잡았다. 기획값이 아니라 확인용이다.

| 적 | HP 배수 | 색 |
| --- | --- | --- |
| 찢어진 악보 | 0.6 | 종이색 (0.88, 0.82, 0.62) |
| \[미정\] | 0.8 | 하늘 (0.50, 0.78, 0.95) |
| 부서진 메트로놈 | 1.0 | 나무 (0.78, 0.60, 0.40) |
| \[미정\] | 1.9 | 노랑 (0.95, 0.78, 0.20) |
| \[미정\] | 2.0 | 초록 (0.35, 0.72, 0.42) |
| \[미정\] | 2.9 | 보라 (0.58, 0.38, 0.85) |
| 망가진 앰프 | 3.4 | 적갈 (0.62, 0.22, 0.18) |
| 보스 | — | 진홍 (0.85, 0.12, 0.25) |

피격 플래시가 흰색이라 밝은 쪽도 흰색까지는 가지 않게 뒀다.
