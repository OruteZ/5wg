# Rules
이 저장소에서 지켜야 하는 규칙.

| 파일 | 내용 |
| --- | --- |
| `git.md` | 커밋 메시지 접두사 |
| `code.md` | 코드를 **어떻게** 쓰는가 — 네임스페이스, 인스펙터 어트리뷰트, 주석, 셀프체크, 조용한 실패 |
| `unity-csharp.md` | **무엇을** 쓰는가 — 2D 물리·입력·시간(dspTime)·메모리·구조 |

`code.md`와 `unity-csharp.md`는 둘 다 `Assets/_Project/Scripts/Runtime/`에 적용된다.
겹치는 주제는 한쪽에만 두고 다른 쪽은 포인터만 갖는다.
